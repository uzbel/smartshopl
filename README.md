# SmartShop — Do'kon Boshqaruv Tizimi

Kichik do'konlar uchun to'liq boshqaruv tizimi. Hech qanday server kerak emas — to'g'ridan-to'g'ri brauzerda ishlaydi.

## Imkoniyatlar

- **Bosh sahifa** — Bugungi va oylik statistika
- **Mahsulotlar** — Qo'shish, tahrirlash, o'chirish
- **Sotish** — Yangi sotuv qayd etish (ombor avtomatik kamayadi)
- **Bugungi sotuv** — Bugun sotilgan barcha mahsulotlar
- **Ombor** — Zaxira holati, kam qolgan mahsulotlar
- **Xarajatlar** — Do'kon xarajatlari (ijara, elektr, maosh...)
- **Egasi xarajati** — Egasi shaxsiy uchun olgan mahsulot/pul
- **Oylik hisobot** — To'liq moliyaviy hisobot
- **Tarix** — Barcha sotuvlar tarixi
- **Sozlamalar** — Do'kon ma'lumotlari

## Ishlatish

1. `index.html` faylini brauzerda oching
2. Demo ma'lumotlar avtomatik yuklanadi
3. Barcha ma'lumotlar `localStorage` da saqlanadi

## Texnologiyalar

- Sof HTML, CSS, JavaScript (framework yo'q)
- Google Fonts (Sora + JetBrains Mono)
- LocalStorage (ma'lumotlar saqlash)
